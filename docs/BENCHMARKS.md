## 🧪 実験 1: 定義式で決まる課題（商品価格 `price_sgd` 決定）

### 概要
- **検証仮説**: 「定義式（原価・利益率等の確定ルール）で決まる課題にAI推論を使ってはならない（式が正しいなら式が最強）」
- **タスク**: Regression（回帰） / サンプル数: 3,000行（学習 2,400 / 検証 600、時系列分割）
- **近傍変数（電線）**: `cost_jpy`, `margin`
- **遠隔変数（WiFi）**: `category`, `sgd_jpy`, `competitor_ratio`, `sale_event`, `review_count`

### 実測結果（検証データ）
| モデル | MAE | RMSE | $R^2$ | 評価 |
| :--- | :---: | :---: | :---: | :--- |
| **現行ルール（固定式・定義式）** | **3.9662** | **5.3146** | **0.9959** | 🏆 **最良（完全一貫性）** |
| 固定式（線形回帰・近傍のみ） | 4.8361 | 6.6239 | 0.9936 | 良好 |
| AI（全域モデル） | 2.3548 | 12.7995 | 0.9761 | ⚠️ 誤差 140.8% 悪化（-93.2%） |
| AI（近傍のみ） | 5.4280 | 14.5670 | 0.9690 | 🛑 誤差 174.1% 悪化（-119.9%） |

### 考察と結論
- 価格のように定義式で決まる値をニューラルネット等のAIで予測させると、**RMSEが5.31から14.57へと2倍以上（+174.1%）に跳ね上がり大改悪**となる。
- 多項式近似AIの誤差（$\epsilon > 0$）が露呈し、武藤理論の「定義式にAIを使ってはならない」が実証された。

## 🧪 実験 2: 外部要因が絡む課題（30日成約判定 `sold_30d`）

### 概要
- **検証仮説**: 「近傍の式を単にAI化するだけでは無駄だが、遠隔変数（WiFi: 為替・競合等）を取り込むことでAIが固定式を超える」
- **タスク**: Classification（2値分類） / サンプル数: 3,000行（学習 2,400 / 検証 600、時系列分割）
- **近傍変数（電線）**: `category`, `price_sgd`, `margin`
- **遠隔変数（WiFi）**: `sgd_jpy`（為替）, `competitor_ratio`（競合価格比）, `sale_event`（セール）, `review_count`（レビュー数）

### 実測結果（検証データ）
| モデル | Accuracy | AUC | LogLoss | 改善率（LogLoss） |
| :--- | :---: | :---: | :---: | :---: |
| 固定式（線形・近傍のみ） | 0.6217 | 0.6539 | 0.6556 | 基準 (0.0%) |
| AI（近傍のみ） | 0.6167 | 0.6325 | 0.6660 | -1.6%（単なるAI化は悪化） |
| **AI（全域・遠隔変数あり）** | **0.6483** | **0.6851** | **0.6327** | 🏆 **+5.0% 改善（総合 +3.5%）** |

### 寄与した変数 TOP5（SHAP / Importance）
1. `price_sgd`（近傍）: 0.0780
2. `category`（近傍）: 0.0547
3. `competitor_ratio`（遠隔）: 0.0163
4. `sgd_jpy`（遠隔）: 0.0117
5. `sale_event`（遠隔）: 0.0077

### 考察と結論
- 近傍の変数をそのまま機械学習に入れるだけでは、過学習やノイズにより逆に精度が -1.6% 悪化する。
- 一方、式に書けなかった「遠隔変数（為替・競合比率・イベント）」を全域AIに学習させることで、初めて有意な改善（+5.0%）が得られた。

## 🧪 実験 3: カオス物理気象予報（Lorenz-96 有効予報時間）

### 概要
状態依存の減衰係数（$c(x)$）と遠隔結合（$G$）を含むカオス時系列系（F=12）における予報可能時間（MTU: 気候値誤差の半分に達するまでの時間）の測定。

### 実測結果
| 手法 | 有効予報時間（MTU） | 相対性能 |
| :--- | :---: | :---: |
| 物理モデル（係数固定・近傍のみ） | 0.80 MTU | 基準 |
| AIモデル（近傍のみ） | 1.10 MTU | 1.38倍 |
| **AIモデル（全域・遠隔結合あり）** | **1.30 MTU** | 🏆 **1.63倍（大幅延伸）** |
| *[理論上限] 真の完全方程式* | *2.00 MTU* | *2.50倍* |

## 🧪 実験 4: 岡さん案件（REVO）感度分析（Sobol Variance Decomposition）

### 概要
事業シミュレーションモデルにおける「資金の谷」と「M12営業利益」に対する入力パラメータの寄与度（Sobol感度解析）を測定。

### 実測寄与度
- **資金の谷（累計キャッシュアウト最小値）の決定要因**:
  1. `設備不具合の件数/月`: **寄与度 0.47**
  2. `原状回復の件数/月`: **寄与度 0.35**
  ➔ キャッシュ危機は「修理・原状回復の突発件数」で82%が決まるため、ここを固定式で厳密管理する方針を導出。
- **M12営業利益の決定要因**:
  1. `有料オーナー数`: **寄与度 0.57**
  2. `オーナー月額`: **寄与度 0.21**
