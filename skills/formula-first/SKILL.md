# Formula-First（固定式ファースト）自動導出スキル

## 目的
武藤佳恭先生の理論に基づき、**「式や定義で求まる問題にAI推論を使ってはならない」**という絶対原則を適用します。
数学的根拠：固定式の誤差は $E = 0$、計算コストは 0円・0ms。AIは多項式近似であるため必ず誤差 $\epsilon > 0$ とトークン消費が発生します。

## 3層カスケード（Muto Cascade Architecture）
1. **Tier 0: 固定式・定義式（Deterministic Formula）**
   - 対象: 算術演算、税計算、割引率、日付・時刻差分、正規表現抽出、テーブル参照、完全一致ルール。
   - 実行: `formula-first "<式や課題>"`
   - 速度: 0.1ms〜1ms / コスト: 0円 / 誤差: 0.0%
2. **Tier 1: ローカル近傍AI（LAYA Multilingual）**
   - 対象: 型付き候補選択、多言語意味分類、フィルタリング。
   - 実行: `laya-cascade "<課題>" "候補1" "候補2" ...`
   - 確信度 0.95 未満は切り捨てず Tier 2 へ保持委託。
3. **Tier 2: 全域AI（System 2 LLM）**
   - 対象: 複雑な文脈理解、非自明なカオス時系列予測、設計・アドバイス。

## CLI の使用方法
```bash
# 算術・割引計算
formula-first "5000円の20%引き"

# 日数・日付差分
formula-first "2026-10-04から2026-12-31までの日数"

# 四則演算
formula-first "(120 + 45) * 8"

# 候補選択（LAYA連携）
laya-cascade "ユーザー認証機能の設計" "auth.ts" "style.css" "README.md"
```
